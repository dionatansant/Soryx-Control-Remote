Política de Privacidade — Soryx Control Remote

Última atualização: 05 de agosto de 2026

O Soryx Control Remote é um aplicativo que transforma um celular em controle remoto de TV via rede local (Wi-Fi). Esta política explica como o aplicativo trata dados dos usuários.

1. Dados coletados

O Soryx Control Remote não coleta, armazena nem transmite dados pessoais a servidores externos. Toda a comunicação entre o celular e a TV acontece exclusivamente dentro da rede local (Wi-Fi) do usuário, por meio de um servidor HTTP local executado no próprio dispositivo (TV). Nenhuma informação é enviada para a internet ou para servidores de terceiros controlados pelo desenvolvedor.

2. Permissões utilizadas

  • Internet / Rede local: usada apenas para o celular se conectar ao servidor local rodando na TV.
  • Serviço em primeiro plano (Foreground Service): mantém o servidor de controle remoto ativo enquanto o app está em uso.
  • Inicialização automática (Boot): permite que o serviço de controle remoto seja reiniciado automaticamente após a TV ligar.
  • Serviço de Acessibilidade: usado apenas em TVs sem acesso root, para simular comandos de navegação (setas, voltar, início, recentes) enviados pelo celular. Essa permissão é opcional e só é necessária quando o dispositivo não possui root.

3. Compartilhamento de dados

Não compartilhamos, vendemos ou transferimos dados a terceiros, pois o aplicativo não coleta dados para além do funcionamento local do controle remoto.

4. Crianças

O aplicativo não é direcionado a crianças e não coleta intencionalmente dados de menores de idade.

5. Alterações nesta política

Esta política pode ser atualizada periodicamente. Alterações serão publicadas nesta mesma página.
